## Findings that matter for DT

1. **Budget loadout (notches, Jades, amulets).** No developer source was found for any of the three budget figures. The Hollow Knight 3→11 figure is the best-supported, with a wiki snippet only. Do not treat the cost numbers as design-grade until checked against the game files or a developer statement.
2. **Stress.** Darkest Dungeon's 100 threshold is consistent across fan-wiki snippets. The 200 outcome is still disputed: Death's Door (wiki), instant death (guide), reset to 150–170 (forum). The Virtue-at-200 reset is the best-supported reading at present, but only from a fan wiki. Odds of 75/25 are unverified.
3. **Banked currency.** Dead Cells' bank-at-Collector model and MIO's Nacre-to-Shii rule are both still secondary. Only Dead Cells has a consistent description (loss on death if not banked), and that description comes from a retail summary.
4. **Combos.** Sea of Stars' persistence is now better supported than round 1 suggested, but still not primary. The cap of 3 is still unverified.
5. **Bonds.** Persona rank numbers conflict across guides. Do not adopt any rank threshold until a primary source is found.

## Design questions this raises for DT

1. **Budget curve.** Should DT's loadout budget start small and grow via story beats or tool knowledge, the way Hollow Knight's notches grow via found items, and what should the first budget be for the Tier 1 prototype with two characters?
2. **Stress consequence at the top.** Should the 200-equivalent in DT be a Death's-Door-style injury (matching the existing blackout and injury system), or a Virtue-reset with no injury? The Darkest Dungeon sources disagree, so the author should choose rather than copy.
3. **Death penalty.** Should unspent XP be bank-or-lose (Dead Cells model, mapped to DT's XP pool and blackout) or recover-from-the-death-spot (Salt and Sanctuary model)? This needs a decision before the blackout system is built.
4. **Combo persistence (T2).** If combos are later approved, should points carry across encounters (Sea of Stars' current reading) or reset per encounter? Combos stay out of T1 until the author approves them.
5. **Bond rank thresholds.** The pair-bond integer needs threshold values. Persona's sources conflict, so the author should set values for DT's own rhythm and micro-choice inputs rather than borrow numbers.
